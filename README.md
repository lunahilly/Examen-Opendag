
> [!IMPORTANT]
> Vergeet niet om ```npm run dev``` te runnen voor je begint met programmeren. En als het niet werkt check dan of je wel in de juiste map zit.


Als je bezig bent met styling run dan het volgende command voor de scss
```
sass resources/scss/style.scss resources/css/app.css --watch
```

als je wat met git wilt doen, dit is de volgorde
```
git add .
git commit -m "message"
git pull
git add .
git commit -m "merge"
git push
```

Als er changes op main staan ga niet ``git merge main`` doen. Laat het Luna weten en zij maakt een pull request aan.
Maar zorg dat je niet op main werkt tenzij echt nodig.
